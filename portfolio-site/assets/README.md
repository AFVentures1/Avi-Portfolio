# Assets — drop your images and videos here

The site works right now with styled placeholders. The moment you add a file
with the matching name below, it appears automatically. No code changes needed.

## Images (recommended)

| File name           | Where it shows              | Suggested size        |
|---------------------|-----------------------------|-----------------------|
| `headshot.jpg`      | Hero photo (right side)     | ~800 x 1000 (portrait)|
| `work-qaffee.jpg`   | Qaffee Point work row       | ~1200 x 750 (16:10)   |
| `work-massai.jpg`   | Massai Group work row       | ~1200 x 750           |
| `work-almas.jpg`    | Almas Electronics work row  | ~1200 x 750           |
| `work-ntv.jpg`      | NTV work row                | ~1200 x 750           |

`.jpg`, `.png`, and `.webp` all work — just keep the exact file name (including
the extension shown above, or change the `src` in `index.html`).

## Videos (optional)

If you add any of these, a play button appears on that work row and opens the
demo in a lightbox:

| File name        | Work row          |
|------------------|-------------------|
| `qaffee.mp4`     | Qaffee Point      |
| `massai.mp4`     | Massai Group      |
| `almas.mp4`      | Almas Electronics |

Your existing videos are one folder up (in the main A&F folder). You can copy
and rename any of them here — for example, copy `Qaffee Point.mp4` in as
`qaffee.mp4`.

Tip: keep videos small (under ~10 MB each) so the site loads fast.
